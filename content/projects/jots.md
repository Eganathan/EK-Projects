# Jots - Google Keep Alternative

An alternative note-taking application to Google Keep, developed to test and explore the strengths and weaknesses of Zoho Catalyst as a backend platform. While the project served its purpose as a learning experience, active development has been discontinued.

## Project Overview

Jots was created as an experimental project to evaluate Zoho Catalyst's capabilities as a backend-as-a-service platform. The application provides core note-taking functionality similar to Google Keep, allowing users to create, organize, and manage their notes efficiently.

## Key Features

- **Note Creation & Management**: Create, edit, and delete notes with ease
- **Organization Tools**: Categorize and organize notes for better productivity
- **Clean Interface**: Simple, intuitive design focused on usability
- **Cloud Sync**: Backend powered by Zoho Catalyst for data persistence
- **Responsive Design**: Works across different devices and screen sizes

## Technologies Used

- **Frontend**: JavaScript, HTML5, CSS3
- **Backend**: Zoho Catalyst
- **Hosting**: Custom domain deployment

## Project Status

While Jots remains live and functional at [jots.eknath.dev](https://jots.eknath.dev), active development has been discontinued. The project successfully served its primary purpose of evaluating Zoho Catalyst's platform capabilities and identifying its strengths and limitations for backend development.

## Learning Outcomes

This project provided valuable insights into:
- Zoho Catalyst's development workflow and tooling
- Backend-as-a-service platform limitations and benefits
- Alternative approaches to traditional backend development
- Rapid prototyping and MVP development strategies

The experience gained from building Jots has informed subsequent technology choices and architectural decisions in other projects.
